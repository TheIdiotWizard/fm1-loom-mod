## Performance: where it stands (FM-1, two cores)
Songs: means 36-50 %, peaks 91-122 %, dropouts 0-51 (house worst, then pop). Per stage before voices: master 7.3 %,
FX II 9.2 % (now on core 1, a block behind), sequencer 2.7 %. Peaks are chord changes: the new chord starts while the
old releases (7 -> 14 voices in a block); each note-on ~27k cycles (voice configuration, mostly flash-cache misses);
each extra "stretch" (a block split at a sequencer event: sample-accurate stepping) ~6 % of a block.
Next levers, in order: (1) note-on set-up off the audio block (second core, or spread across blocks); (2) fewer / cheaper
stretches (coalesce events per block?); (3) brocade's per-saw cost. Predictive admission was tried (reuse releasing
voices): only 128 -> 124 on house, reverted. RAM is the tightest resource now (3.4 KB left).
