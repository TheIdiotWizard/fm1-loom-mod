# XY-1: the OP-XY experience on the FM-1

A pocket groovebox for the M-VAVE FM-1 that recreates the OP-XY's way of working as faithfully as the
hardware allows: eight instrument tracks with synth engines, a 64-step sequencer with step components
and parameter locks, players (arp, maestro, hold), punch-in FX, a brain track that transposes the song
diatonically, a tape track, two send-effect tracks, a mixer with EQ, saturator and master compressor,
scenes and a song. Built on FoMni's platform layer (Felucca) with NuSaw's second core, X0X's sequencer
discipline and Polly's menu paradigm. "Inspired by the OP-XY" on the site; no trademark in the name.

Sources: the OP-XY guide (teenage.engineering/guides/op-xy), its firmware changelog up to 1.2.0, and
reviews (Sound On Sound, CDM, Mehatronika, Elektronauts, op-forums). Research notes in the session
scratchpad: `opxy_manual.md`, `opxy_reviews.md`, `reuse_survey.md`.

## What the OP-XY experience is

Reviewers agree on one loop: a short boring sequence, then step components (random values are the
magic), then a brain chord progression at a slow track scale, then punch-in FX while it plays, then
scenes recalled by number. The grammar is small: one sound per track, four modules of four knobs each
with fixed knob colours, shift means "what kind", holding a step means "what is on it". XY-1 keeps the
grammar and the loop, not the surface.

The pains to avoid: a note limit per pattern, no probability trigs, clumsy p-lock editing, no
start-from-bar, one shared drum envelope.

## Hardware mapping

The FM-1: 27 keys (16 white F3..G5, 11 black), 14 buttons (FX SEL ENV LFO EDIT GLO HOME SAVE ARP SEQ
PLAY REC OCT- OCT+), 7 encoders (SELECT ALGORITHM PRESETS K1-K4), MASTER pot, 240x240 screen.

| OP-XY | XY-1 |
|---|---|
| track buttons 1-8, aux 9-16 | ALGORITHM turns through the tracks: 1-8, then BRAIN, PUNCH, TAPE, FX I, FX II; black keys 1-8 on the Steps and Arrange pages jump to a track |
| M1 engine / M2 envelope / M3 filter / M4 LFO | EDIT / ENV / FX / LFO buttons (Polly: a button per set of knobs; SELECT turns its pages) |
| four knobs, dark grey → white | K1-K4, each page's four values; the knob strip shows the four shades |
| 16 step keys | the 16 white keys on the Steps page (SEQ); OCT-/OCT+ page the bars |
| musical keyboard | the 27 keys on every page but Steps and Arrange |
| shift + step + natural = component | hold a step (or several) + a black key = component (11 black keys = 11 components); K4 while holding = its value |
| hold a step + knob = p-lock | the same |
| shift + key = punch-in FX | hold HOME + a key (low 12 keys = drum FX, upper 15 = melodic FX); on the PUNCH track the keys fire directly |
| shift + accidental = scene | the 16 white keys on the Arrange page (HOME) = scenes 1-16; black keys = mutes |
| bar page | Steps page 2 (SELECT): length, scale, quantise, groove, note length, shape |
| players button | ARP button: arp / maestro / hold |
| tempo / mix / project / com | Arrange page knobs (tempo, groove, swing, metronome); GLO: Mix, Master, Setup, Status |
| record / play / stop | REC / PLAY (PLAY twice = from the start; stop = PLAY while playing; PLAY while stopped with REC = count-in) |
| shift + record = undo | HOME + REC undo, HOME + PLAY redo |
| encoder click | SEL opens the page's list of settings and actions; PRESETS steps the page's item |

## Pages (Polly's paradigm)

Every page: header (page name, tempo, REC dot, unsaved), main band (the picture), tag line (track ›
pattern › scene), knob strip (four values, the knob last turned in coral), encoder line, footer (what
the keys and buttons do here). Hold a button for a second: a help card. SEL: a list of the page's
settings and actions. Colours: Polly's paper palette; teal = sounding now, coral = you, ink = what
stays. The knob strip shows the OP-XY's four shades (dark, mid, light grey, outlined white) as small
swatches beside the knob names so the manual's language ("the dark grey knob") still applies.

| Button | Pages (SELECT turns them) | Keys |
|---|---|---|
| HOME | Arrange: 8 + 3 rows of patterns with playheads, the scene; page 2 Song (a chain of scenes) | white = scenes 1-16 (empty: clone the current; while playing: at the bar), black = mutes (1-8 tracks, 9-11 brain/punch/tape) |
| SEQ | Steps: the bar shown as 16 cells (notes, component, lock marks, playhead); page 2 Bar (length, scale, quantise, groove, note length, shape, bars) | white = steps; black = component (with a step held) or the drum sound shown (drum track) |
| EDIT | Engine: the engine's four knobs and its picture; page 2 Play (voice mode, portamento, bend, volume) | play |
| ENV | Envelope: amp ADSR; page 2 filter ADSR | play |
| FX | Filter: cutoff, resonance, env amount, keytrack; page 2 Sends (fx I, fx II, tape, filter type) | play |
| LFO | LFO: type, speed, amount, destination; page 2 (type-specific) | play |
| ARP | Players: type (off/arp/maestro/hold) + its knobs; REC here = record the maestro chord | play (through the player) |
| GLO | Mix (level, pan, fx I, fx II for the track; black keys pick the strip), Master (EQ + blend, saturator, comp, level), Setup, Status | — |
| SAVE | saves; hold + white key = save the sound as user preset n | |

Aux tracks have their own Engine page under EDIT (BRAIN: mode, key, scale, degree; PUNCH: latch;
TAPE: pitch, speed, length, mix; FX I/II: effect, its four params) and their own Steps (the same
sequencer: brain steps = degrees, punch steps = effects, tape steps = segments).

## The sequencer

X0X's discipline: the sequencer runs in the audio interrupt, sample-accurate (`seq_until_event` /
`seq_advance`), the UI edits plain data from the main loop; every field the interrupt reads is a byte
or an aligned word.

- 11 sequenced tracks (8 instrument + brain, punch, tape), 8 patterns each, 64 steps (4 bars of 16),
  up to 4 notes a step (chords: notes held together are remembered and written as one). No note
  limit beyond that.
- Per track-pattern: length (1-64), track scale (1/2, 1, 2, 3, 4, 6, 8, 16 sixteenths a step),
  quantise, groove (swing, half shuffle, bombora, wobbly, gaussian, accents, island nod: timing +
  velocity tables), note length, shape (smoothing between locks).
- Per step: notes[4], velocity, length (quarter steps), nudge (ticks), component + value, condition
  (always, chance %, or A:B of every B passes: the probability the OP-XY lacks).
- Components (11, on the black keys): pulse, hold, multiply, velocity, ramp up, ramp down, random,
  portamento, bend, jump, skip. Values 1-9 and random, as the OP-XY's tables.
- Parameter locks: lanes (X0X's motion), hold a step + turn a knob; the shape knob ramps between locks.
  Recording a knob while REC is on writes locks.
- Step entry: Steps page, the remembered note(s), press a step; hold a step to see it (K1 velocity,
  K2 length, K3 nudge, K4 condition); hold a step + a later step = length; hold a step + black key =
  component. Live record (REC + PLAY, quantised, overdub); step record (stopped, REC, play keys:
  the cursor advances; OCT± moves it). Count-in. Drum tracks: the shown sound's steps (PRESETS or a
  black key picks the sound).
- Players: arp (speed, pattern up/down/updown/random/played, range, hold; length), maestro (a recorded
  chord, played transposed by one key: roll, pattern, hold), hold.
- Brain: key + scale (manual, or auto-detected from the routed tracks' notes), routing per track,
  link; the brain's degree (a key pressed on the BRAIN track, or its steps) transposes routed tracks
  diatonically. Drum tracks never transpose.
- Punch-in FX: 12 drum (mute, stutter, fill, pan, half fill, octave up, echo, kick/snare fill, short,
  hats fill, long tails, random sound) and 15 melodic (mute, stutter, loop 4, pan, octave up, octave
  down, delay up, reverb up, filter down, filter up, ramp, random notes, half time, double time,
  reverse); momentary, combinable, mute wins; sequenced on the PUNCH track.
- Tape: a quarter-rate mono ring of the last 16 steps of the routed tracks; on the TAPE track the 16
  white keys loop a segment while held (pitch, speed, length, mix).
- Scenes: 16; a scene = the pattern of each track + mutes + brain key/degree. Song: up to 64 scene
  slots with repeats, loop on/off.
- Clock: internal, or MIDI clock in (USB / TRS); clock and transport out.

## Sound

Voices: a pool of 16 synth voices (up to 6 a track) + 8 drum voices; half the sounding voices render
on the second core (NuSaw's dealing), one core when it is absent or barred; an overload guard trims
polyphony (X0X's 92 % / 85 % rule). Float, 44.1 kHz, 64-sample chunks for control, `fastmath.h`.

Engines (8 synths + drumline), four parameters each as the OP-XY names them:

| Engine | Model | Knobs |
|---|---|---|
| simple | PolyBLEP saw ↔ square, noise, stereo detuned pair | shape, pw, noise, stereo |
| prism | two oscillators at a ratio, detune, stereo | shape, ratio, detune, stereo |
| wavetable | 8 tables × 16 frames (int16 in flash), position, warp (phase distortion), drift (phase mod toward audio rate) | table, position, warp, drift |
| axis | 2-op FM, ratio from detune to fifths, shape, tremolo | tone, ratio, shape, tremolo |
| epiano | 2-op FM tine + bar, texture, punch | tone, texture, punch, tine |
| organ | drawbars (additive sines), bass, tremolo | type, bass, tremolo, speed |
| hardsync | hard-synced saw with free master, sub, noise, low cut | freq, sub, noise, lowcut |
| dissolve | two sines modulated by filtered noise (AM, FM) | swarm, am, fm, detune |
| drumline | 11 sounds on the black keys: kick, snare, closed hat, open hat, clap, low tom, high tom, conga, shaker, fm, resonator; per sound model, tune, tone, decay, pan, level | type, tune, tone, decay (the sound shown) |

Per voice: two ADSRs (amp, filter), SVF (LP 12, LP 24, HP, BP), velocity, keytrack, portamento,
voice modes poly / mono / legato, an LFO (value, tremolo, random, duck) to a destination (any knob
of the engine / filter / envelope pages), sends to fx I, fx II and tape.

FX I / FX II (one effect each: chorus, delay, distortion, lofi, phaser, reverb; fx I can feed fx II).
Master: 3-band EQ with blend, saturator (gain, clip, tone, blend), compressor, limiter (X0X's
master.c), percussion / melodic group levels.

Presets: 64 factory sounds across the engines (two pages of PRESETS per engine), 16 user slots.
Scramble (randomise the sound) in the Engine page's list.

## Memory plan

RAM: 96 KiB .bss (voices, sequencer runtime, UI, USB) + 336 KiB pool: canvas 69 K, pattern store
(11 × 8 × 648 B = 57 K), lanes 96 × 68 B = 6.5 K, delay (0.75 s, int16, ping-pong) 66 K, reverb
(9W9's int16 combs) 24 K, tape (quarter rate, 2.97 s) 64 K, chorus 8 K, USB audio ring 8 K, store
buffers 8 K. About 315 K; the build fails under 8 K spare, so the tape or delay shrinks first.

Flash: code + wavetables (64 K) + fonts, well under the 581 K slot. Projects: four slots, each an LZ
stream (X0X's lz.c) across objects in Felucca's data area; user presets in one object; the panel
calibration where FoMni keeps it. Package identity `FM-1_10` + version digits (every single digit is
taken): dev `FM-1_1000`, releases `FM-1_10XXYYZZ`. USB name "XY-1".

## Architecture (files)

- `firmware/src/seq/pattern.h` data model; `seq.c/.h` clock, steps, components, players, brain,
  punch, groove; runs in the interrupt through a sink of callbacks (note on/off with pitch, velocity,
  glide; drum hits; punch state; tape segment; MIDI out; UI playheads).
- `firmware/src/dsp/synth.c/.h` voices and the eight engines; `drumline.c/.h`; `fx.c/.h` the six
  effects; `master.c/.h` (X0X's + EQ); `tape.c/.h`; `wavetables.h` generated by `tools/gen_wavetables.py`.
- `firmware/src/app/engine.c/.h` the mixer, the command queue, voice allocation, the two cores, the
  guard; `project.c` save / load / scenes / song; `pages.c` (Polly's framework: header, tag, knob
  strip, encoder line, footer, cards, lists, messages) + the page drawings; `ui.c` input and state;
  `presets.h` factory sounds.
- Host simulator `host/xy_host.c` (FoMni's, with X0X/SPH's `param`, `load`, `steps` commands), web
  emulator `web/emu`, tests `tests/` (sequencer unit tests, engine level tests, scenario scripts,
  silent WAVs). Screen reader: `announce.c`, `words.tsv`, `speak()`; the audit passes.

## Testing

Host: `tests/run_tests.sh` builds and runs the sequencer tests (components, conditions, groove,
scales, brain transposition), the synth tests (every engine and preset renders, levels in range, no
NaN), the FX tests, storage, the update path, the emulator, and the scenarios (first run, a beat,
a bass line with components, a brain progression, punch-in, scenes, save and reboot, the reader).
Device: PERF on the Status page (CPU %, peak, voices, core 2 state); the user flashes.

## Out of scope

Samplers (no sample RAM), CV / external audio / external MIDI aux tracks, gyroscope, Bluetooth,
projects beyond four, songs beyond one per project, user wavetables, tunings.
